# AER PDF Studio — launch announcement draft

**AER PDF Studio** is an open-source Windows PDF workspace being developed for engineering drawing reviews and bilingual document workflows.

Current community-preview features include PDF viewing, merge/split/rotate, calibrated drawing measurements, rectangle and polygon takeoffs, side-by-side revision comparison, a CSV review register, and Arabic/English text search. For scanned pages, optional offline Tesseract OCR can export text or searchable PDFs. An experimental OCR mode attempts to preserve the original vector PDF content while adding searchable text.

The project uses Python, Tkinter, PDFium, pypdf, and ReportLab. Contributions and bug reports are welcome—especially from civil/structural/architectural teams and people working with Arabic text.

**Repository:** https://github.com/ADAMELR/AER-PDF-Studio

**Downloads:** https://github.com/ADAMELR/AER-PDF-Studio/releases (when a reviewed prerelease has been published)

**Important:** This is a preview, not a substitute for professional drawing checks or certified quantity takeoffs. OCR and drawing alignment require manual verification. The installer is not code-signed; Tesseract must be installed separately for OCR.
