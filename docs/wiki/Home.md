# AER PDF Studio Wiki

Welcome to the AER PDF Studio user and contributor knowledge base. AER PDF Studio is a free, open-source Windows PDF workspace developed for engineering drawings and Arabic/English document workflows.

**Current documented version:** Community Preview 1.4. This is experimental software: keep original PDFs and verify measurements, OCR output and drawing comparisons.

## Start here

- [Installation and first run](Installation.md) — portable Windows download and Python source setup
- [PDF tools and viewing](PDF-Tools.md) — open, merge, split, rotate and rectangle markup
- [Engineering measurements](Engineering-Measurements.md) — calibration, length, area, polygon and CSV register
- [Drawing revision comparison](Drawing-Comparison.md) — alignment, reference points and revision register
- [Arabic language and OCR](Arabic-OCR.md) — bilingual interface, text search, Tesseract setup and OCR export modes
- [Troubleshooting](Troubleshooting.md) — common installation, PDF and OCR errors
- [Contributing and development](Development.md) — testing, source structure and safe contributions

**Privacy and safety:** No built-in cloud upload is implemented. Only open PDFs you trust. OCR needs Tesseract installed separately. The application is not a certified takeoff, document-signing or engineering verification system.
